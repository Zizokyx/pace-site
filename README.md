# Alin AI Analytics Premium Website

Site premium, minimalist, tech, bilingv RO/EN, pentru consultanță BI + Power Platform + Copilot Studio.

## Ce include
- Landing page premium dark tech
- Toggle limbă RO/EN cu salvare în localStorage
- Secțiuni: hero, soluții, poziționare, metodă, calculator ROI, pachete, contact
- Design responsive pentru telefon
- Formular mailto fără backend

## Fișiere
- `index.html`
- `styles.css`
- `script.js`
- `assets/favicon.svg`

## De schimbat înainte de publicare
1. În `script.js`, caută `contact@alin-data-ai.com` și înlocuiește cu emailul tău.
2. În `index.html`, poți schimba brandul `Alin AI Analytics` dacă vrei alt nume.
3. Dacă vrei formular real, conectează-l la Formspree, Netlify Forms, Supabase sau backend.

## Deploy
Urcă folderul pe Vercel / Netlify ca static site.
